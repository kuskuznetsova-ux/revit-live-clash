# Revit Live Clash

Плагин для Revit 2022–2024: подсвечивает красным элементы, которые геометрически пересекаются, в активном виде.

## Кнопки (вкладка «Надстройки» → панель Live Clash)
- **Проверить коллизии** — полный поиск пересечений в активном виде и подсветка (переопределение графики вида).
- **Live вкл/выкл** — пересчёт на лету (IUpdater): при изменении геометрии или добавлении элементов подсветка обновляется сама.
- **Сбросить подсветку** — убирает переопределения.

Штатные пересечения игнорируются: окна/двери в стене, вложенные семейства, соединённые (Join) элементы.

## Сборка и установка
```
dotnet build -c Release /p:RevitDir="C:\Program Files\Autodesk\Revit 2022"
```
Скопировать `RevitLiveClash.dll` и `RevitLiveClash.addin` в `%AppData%\Autodesk\Revit\Addins\2022\`
(в `.addin` при необходимости указать полный путь к dll).

Для Revit 2025+ нужен target `net8.0-windows`.
